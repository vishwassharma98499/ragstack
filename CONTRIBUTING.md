# Contributing to DocChat RAG

## Setup
1. Fork the repo and clone locally
2. Copy `backend/.env.example` to `backend/.env`
3. Run `make dev` to start the stack
4. Run `make test` to verify everything works

## Code Style
- Backend: follow PEP 8, max line length 120
- Frontend: Prettier defaults
- Commits: use conventional commits (feat:, fix:, docs:, test:, chore:)

## Pull Requests
- One feature per PR
- Include tests for new backend endpoints
- Update README if adding new configuration options
